# lazyparser

Ленивый парсер, кидаешь ссылку, возвращается html в ии, а он обрабатывает и получаешь информацию о товаре. в функции общения с иишкой можно менять на нужный запрос к ней

Подключение к тг осуществляется через прокси socks5, в данном проекта 9150 порт 127.0.0.1 при открытом луковом браузере. Можно настроить и вбить в докер "t.0.P.P.c" функционал для независимого подключения прокси от включенного лукового браузера.
По эффективности не сравниться с парсерами, улучшить можно либо изменив модель ии и урезанием html файла до передачи в модель
